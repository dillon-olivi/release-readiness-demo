HOW THE PROJECT WORKS

One set of rules, tested at multiple layers

The dashboard is backed by reusable release logic and a Node.js API. Automated tests check the rules directly, validate the API, and exercise the complete browser workflow.

01

Release rules

A reusable module calculates pass rate and determines whether every deployment requirement is met.

calculateReleaseSummary()
02

REST API

Node.js endpoints expose release state, accept test results, validate input, and reset the demo.

GET /api/release
03

Automated tests

Unit, API, and UI tests cover business rules, invalid requests, state changes, and the main user flow.

unit → API → UI
04

CI/CD pipeline

GitHub Actions runs the full suite and publishes the site only when the quality checks succeed.
