HOW THE PROJECT WORKS

How it works

The dashboard, API, and tests all use the same release logic. Unit tests check the rules directly, API tests verify the server responses, and browser tests confirm the full user workflow.

01

Release rules

A reusable module calculates pass rate and determines whether every deployment requirement is met.

calculateReleaseSummary()
02

REST API

The Node.js API returns the current release state, accept test results, validate input, and reset the demo.

GET /api/release
03

Automated tests

Unit, API, and UI tests cover business rules, invalid requests, state changes, and the main user flow.

unit → API → UI
04

CI/CD pipeline

GitHub Actions runs the full suite and publishes the site only when the quality checks succeed.

test → report → deploy
