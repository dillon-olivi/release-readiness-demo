START HERE
==========

You do not need to install Node.js to publish this project.
Recruiters do not need to download or install anything.

1. Open GITHUB_SETUP.md.
2. Create a public GitHub repository named: release-readiness-demo
3. Upload everything inside this folder.
4. Enable Settings > Pages > Source: GitHub Actions.
5. Replace YOUR_GITHUB_USERNAME in README.md.

GitHub will run the tests and host the live demo automatically.
