# Portfolio completion checklist

## Required before applying

- [ ] Create the public `release-readiness-demo` GitHub repository.
- [ ] Upload every project file, including the hidden `.github` folder.
- [ ] Enable GitHub Pages with **GitHub Actions** as the source.
- [ ] Confirm **Quality Checks & Live Demo** passes in the Actions tab.
- [ ] Replace `YOUR_GITHUB_USERNAME` in `README.md`.
- [ ] Open the live demo and published test report in an incognito window.
- [ ] Add the repository and live demo links to your resume and LinkedIn.

## Ownership work before an interview

- [ ] Explain `calculateReleaseSummary()` without reading from the file.
- [ ] Explain why malformed API input returns HTTP 400.
- [ ] Add one unit test yourself.
- [ ] Add one API or UI test yourself.
- [ ] Change one visible sentence or metric in the interface.
- [ ] Practice a 60-second project walkthrough.

## Strong next improvements

- [ ] Persist release data with SQLite.
- [ ] Add an OpenAPI specification and response-schema validation.
- [ ] Add accessibility checks with `@axe-core/playwright`.
- [ ] Add a test-data factory or Playwright fixture.
- [ ] Add a pull-request template describing test evidence.
